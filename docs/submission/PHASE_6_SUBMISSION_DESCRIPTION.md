# SecureOps Guardian submission description

SecureOps Guardian helps an on-call platform/security engineer repair a Kubernetes security regression without giving an agent production control. In the demo, a checkout deployment adds unrestricted egress. Two bounded TrueForge child threads join the exact GitHub change to explicitly synthetic deployment, alert, reachability, and dependency evidence. Guardian reports a cited `High` finding while preserving actual data access as `Unknown`.

This is more than an incident summary or scanner result. A deterministic verifier runs in a Daytona sandbox against four states: last-known-good, suspect, deny-all, and Guardian repair. It reproduces the exposure, rejects deny-all because it breaks checkout's PostgreSQL path, and accepts an exact least-privilege NetworkPolicy. The stock TrueForge OpenUI card presents the finding, evidence IDs, proof matrix, exact patch, proposal hash, limitations, approval state, and PR link, with a complete Markdown recovery rendering available if the card cannot render.

Human control is part of the product contract. The demo shows the preserved real TrueForge trace in which branch, file, and pull-request writes each paused for separate human approval. The exact proposal is bound to one repository, branch, file, diff, and hash. It then shows the current retry verifying and reusing the existing public remediation PR without another write or approval. Guardian never merges, deploys, accesses a cluster, or claims that static proof establishes live reachability, data access, or exfiltration.

Sponsor capabilities are necessary and visible: model routing, dynamic sub-agents, official and custom MCP connectors, Daytona sandbox execution, persistent sessions, human tool approval, and stock Generative UI. GitHub evidence is real; operational evidence is owned synthetic fixture data. Qodo reviewed representative merged PR #3 in two passes; all five applicable findings were fixed and the review history remains public. AI assistants supported development and review, while the operator retained responsibility for credentials, approvals, evidence, public visibility, recording, and submission.

Known limits: one owned repository, one synthetic incident, one NetworkPolicy rule, two child investigations, and one PR. The current safe public state demonstrates deterministic PR reuse; it is not reset to manufacture a new creation path.
